These tutorials are organized by task, not by internal subsystem. Start with the task you need to complete, then use the linked concept or reference page when you need more detail on box types.

## Which box type should I use?

| I want to... | Use | Tutorial |
|---|---|---|
| Run Claude Code in a sandbox | [**SimpleBox**](/reference/python/box-types) | [Claude Code](/tutorials/claude-code-integration) |
| Run a shell command in isolation | [**SimpleBox**](/reference/python/box-types) | [Quick start](/getting-started/quickstart-nodejs) |
| Execute AI-generated Python code | [**CodeBox**](/reference/python/box-types) | [Execute AI-generated code](/tutorials/code-execution) |
| Upload and download files | [**SimpleBox**](/reference/python/box-types) or [**CodeBox**](/reference/python/box-types) | [Upload and download files](/tutorials/file-transfer) |
| Connect an LLM to a sandbox | [**CodeBox**](/reference/python/box-types) | [Connect to an LLM](/tutorials/llm-integration) |
| Automate a browser | [**BrowserBox**](/reference/python/box-types) | [Automate a browser](/tutorials/browser-automation) |
| Control a full desktop | [**ComputerBox**](/reference/python/box-types) | [Automate a desktop](/tutorials/desktop-automation) |
| Run an interactive shell session | [**InteractiveBox**](/reference/python/box-types) | [Interactive terminal](/tutorials/interactive-terminal) |
| Run Node.js, Go, Rust, or any tool | [**SimpleBox**](/reference/python/box-types) | [Run any language](/tutorials/run-any-language) |
| Run a server and access it from the host | [**SimpleBox**](/reference/python/box-types) | [Long-running services](/tutorials/long-running-services) |
| Handle errors and debug failures | All | [Error handling](/tutorials/error-handling) |

<Tip>
  Not sure where to start? Begin with [CodeBox](/reference/python/box-types) for AI-generated code execution, then move into the task-specific tutorials below.
</Tip>
