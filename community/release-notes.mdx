This page is the single release entry point exposed in navigation.

Use it for:

- release summaries,
- dated release highlights,
- upgrade notes,
- links to canonical source material such as GitHub releases.

## Release publishing standard

Every release entry on this page should include:

1. Exact version number.
2. Release date in absolute form.
3. Scope of impact.
4. Breaking changes, if any.
5. Links to the detailed source of truth.
