This page is the in-docs changelog for BoxLite.

Use it to record:

- released versions
- absolute release dates
- notable changes
- breaking changes
- upgrade notes
- links to canonical source material such as GitHub releases

This page should describe what shipped, not what might ship later.

## Changelog Standard

Each release entry should include:

1. exact version number
2. release date in absolute form
3. summary of the change
4. breaking changes, if any
5. upgrade notes when user action is required
6. link to the canonical source of truth

## Current Source of Truth

If a detailed tag-by-tag ledger, pre-release artifact list, or signed release asset is needed, use GitHub Releases.

<Note>
  For tags, artifacts, and pre-releases, see [GitHub Releases](https://github.com/boxlite-ai/boxlite/releases).
</Note>

## Publishing Guidance

When updating this page:

- prefer short release summaries over long marketing copy
- use exact dates, not relative phrases like "today" or "recently"
- call out breaking changes explicitly
- do not duplicate speculative roadmap content here

## Relationship to Other Pages

- This page replaces the old idea of a separate docs-only "release notes" section.
- It should be the only changelog-style page exposed in navigation.
- Roadmap and contribution guidance should live in GitHub or other project-maintained collaboration channels, not in the primary docs navigation.
