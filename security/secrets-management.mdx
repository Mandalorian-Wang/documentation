# Secrets Management

BoxLite provides robust secrets management capabilities that enable secure handling of sensitive data such as API keys, passwords, tokens, and certificates. This documentation covers how BoxLite handles secrets, environment variable management, and secret rotation patterns.

## Overview

Secrets management in BoxLite is designed to keep sensitive data secure throughout its lifecycle. Unlike traditional approaches that embed secrets in code or configuration files, BoxLite provides isolation and controlled injection mechanisms that minimize exposure risk.

### Why Secrets Management Matters

For enterprise deployments, proper secrets management is critical:

- **Security**: Prevent credential leaks in logs, files, and memory
- **Compliance**: Meet regulatory requirements for data protection
- **Operational Efficiency**: Enable secret rotation without code changes
- **Auditability**: Track secret access and usage

## Secret Types

BoxLite supports multiple types of secrets, each with appropriate handling mechanisms.

### API Keys and Tokens

API keys and tokens are the most common secret types. They provide authentication to external services.

| Type | Example | Handling |
|------|---------|----------|
| API Keys | `sk-abc123...` | Injected via environment variables |
| OAuth Tokens | `ya29.a0AfH6...` | Short-lived, auto-refreshed |
| JWT Tokens | `eyJhbGci...` | Passed at execution time |

### Database Credentials

Database credentials include usernames, passwords, and connection strings.

```python
# Pass database credentials securely
box.exec(
    "python manage.py migrate",
    env={
        "DB_HOST": "db.example.com",
        "DB_USER": "app_user",
        "DB_PASSWORD": "secure_password_123"  # Injected, not stored
    }
)
```

### Certificates and Private Keys

TLS certificates and private keys require special handling for secure storage and injection.

```python
# Certificate-based authentication
box.exec(
    "python app.py",
    env={
        "TLS_CERT": "/secrets/cert.pem",
        "TLS_KEY": "/secrets/key.pem"
    },
    secrets_files=[
        "/path/to/cert.pem",
        "/path/to/key.pem"
    ]
)
```

## Environment Variable Handling

BoxLite provides sophisticated environment variable handling that separates secrets from regular configuration.

### Secret Injection

Secrets are injected into the Box environment at execution time, not stored persistently:

```python
from boxlite import BoxOptions, SecretSource

# Configure secrets injection
box_options = BoxOptions(
    secrets=[
        SecretSource.env_var("API_KEY"),  # From host environment
        SecretSource.vault("db-password", path="secret/database"),  # From Vault
        SecretSource.file("/secrets/api-token.txt"),  # From file
    ]
)

# Execute with secrets injected
result = await box.exec("python app.py", env={"APP_ENV": "production"})
```

### Environment Sanitization

BoxLite automatically sanitizes environment variables to prevent secret leakage:

```python
security_options = SecurityOptions(
    sanitize_env=True,  # Enable environment sanitization
    blocked_env_vars=[
        "AWS_SECRET_ACCESS_KEY",
        "GITHUB_TOKEN",
        "DATABASE_PASSWORD"
    ],  # Explicitly block sensitive vars
    allowed_env_vars=[
        "PATH",
        "HOME",
        "LANG"
    ]  # Whitelist safe vars
)
```

### Secret Masking in Logs

BoxLite automatically masks secrets in log output:

```
# Original command
python app.py --api-key sk-abc123secret

# In logs (masked)
python app.py --api-key sk-***MASKED***
```

## External Secrets Integration

BoxLite integrates with popular secrets management systems for enterprise deployments.

### HashiCorp Vault Integration

HashiCorp Vault provides enterprise-grade secrets management:

```python
from boxlite import VaultSecrets

# Configure Vault integration
vault_config = VaultSecrets(
    address="https://vault.company.com:8200",
    auth_method="kubernetes",
    role="boxlite-prod",
    secrets_path="secret/data/boxlite"
)

# Use Vault secrets in execution
result = await box.exec(
    "python app.py",
    secrets=vault_config.get(["api-key", "db-password"])
)
```

### AWS Secrets Manager Integration

```python
from boxlite import AWSSecretsManager

# Configure AWS Secrets Manager
aws_secrets = AWSSecretsManager(
    region="us-east-1",
    profile="production"
)

# Retrieve secrets at runtime
secrets = await aws_secrets.get("prod/api-key", "prod/db-password")

result = await box.exec(
    "python app.py",
    env=secrets
)
```

### Azure Key Vault Integration

```python
from boxlite import AzureKeyVault

# Configure Azure Key Vault
azure_kv = AzureKeyVault(
    vault_url="https://company.vault.azure.net",
    tenant_id="your-tenant-id",
    client_id="your-client-id",
    client_secret="your-client-secret"
)

# Use secrets
secrets = await azure_kv.get("api-key", "db-password")
```

### Google Cloud Secret Manager Integration

```python
from boxlite import GCPSecretManager

# Configure GCP Secret Manager
gcp_secrets = GCPSecretManager(
    project_id="my-project",
    credentials_path="/path/to/credentials.json"
)

# Retrieve secrets
secrets = await gcp_secrets.get("api-key", "database-password")
```

## Secret Rotation Patterns

Regular secret rotation is essential for security. BoxLite supports multiple rotation strategies.

### Manual Rotation

For simple use cases, rotate secrets manually:

```python
# Update secret via file
await box.upload("/new/api-key.txt", "/secrets/api-key.txt")

# Or update via environment
os.environ["API_KEY"] = "new_secret_value"

# Next execution uses new secret
result = await box.exec("python app.py")
```

### Automated Rotation with Vault

When using HashiCorp Vault, enable automatic rotation:

```python
from boxlite import VaultSecrets, SecretRotation

# Configure automatic rotation
vault_config = VaultSecrets(
    address="https://vault.company.com:8200",
    auth_method="kubernetes",
    role="boxlite-prod",
    auto_rotate=True,
    rotation_interval=3600,  # Rotate every hour
    rotation_strategy=SecretRotation.recreate  # Recreate secrets
)

# Secrets are automatically refreshed
result = await box.exec("python app.py")  # Uses current secrets
```

### Rotation via Deployment

For template-based deployments, rotate by updating the template:

```python
# Update template with new secrets
await box.create_template(
    name="app-template:v2",
    description="Updated secrets",
    secrets={
        "API_KEY": vault_config.get("api-key"),
        "DB_PASSWORD": vault_config.get("db-password")
    }
)

# New boxes use rotated secrets
new_box = await runtime.create(template="app-template:v2")
```

## Secret Storage

BoxLite implements multiple layers of secret storage security.

### In-Memory Security

Secrets exist only in memory during execution:

```python
box_options = BoxOptions(
    # Secrets loaded into memory only
    secrets_in_memory=True,
    secrets_encrypted=True,  # Encrypt in memory
    memory_limit_mb=256  # Limit secret storage
)
```

### Temporary Files

When secrets must be written to files (for tools that require file paths):

```python
# Use secure temporary files
box_options = BoxOptions(
    secrets_temp_dir="/run/boxlite/secrets",  # tmpfs
    secrets_mode=0o600,  # Owner read/write only
    cleanup_on_exit=True  # Delete on box termination
)
```

### Disk Encryption

For persistent secret storage (templates):

```python
# Enable disk encryption for templates with secrets
await box.create_template(
    name="secure-template:v1",
    encrypted=True,
    encryption_type="luks",
    secrets=["api-key", "db-password"]  # Stored encrypted
)
```

## Best Practices

Follow these practices for secure secrets management in BoxLite.

### Do's

```python
# DO: Inject secrets at runtime
result = await box.exec("python app.py", env={"API_KEY": api_key})

# DO: Use external secrets management
secrets = await vault.get("api-key")
result = await box.exec("python app.py", env=secrets)

# DO: Enable environment sanitization
security = SecurityOptions(sanitize_env=True, seccomp_enabled=True)

# DO: Rotate secrets regularly
await vault.rotate("api-key", interval_days=30)
```

### Don'ts

```python
# DON'T: Store secrets in code
# BAD:
result = await box.exec("python app.py --key my_secret_key")

# DON'T: Commit secrets to version control
# BAD: secrets = {"api_key": "sk-abc123"} in config files

# DON'T: Disable environment sanitization
# BAD:
security = SecurityOptions(sanitize_env=False)  # Dangerous!

# DON'T: Log secrets
# BAD:
logger.info(f"API key: {api_key}")  # Secrets in logs!
```

## Secret Access Auditing

BoxLite logs all secret access for security monitoring:

```python
# Configure secret access logging
audit_config = AuditConfig(
    log_secret_access=True,
    log_secret_rotation=True,
    alert_on_secret_exposure=True
)
```

### Audit Events

| Event | Description |
|-------|-------------|
| `secret_accessed` | Secret read from storage |
| `secret_injected` | Secret injected into box |
| `secret_rotated` | Secret rotated |
| `secret_exposed` | Secret found in logs/output |
| `secret_blocked` | Secret access denied |
