This page is the setup hub for BoxLite. It does three things:

1. Confirm your machine can run BoxLite.
2. Send you to the correct language quickstart.
3. Keep BoxLite setup separate from BoxRun operations.

## System requirements

BoxLite runs lightweight micro-VMs and requires hardware virtualization support.

| Platform | Architecture | Requirements |
|---|---|---|
| macOS | Apple Silicon | macOS 12+ (Monterey or later) |
| Linux | x86_64 | KVM enabled (`/dev/kvm` accessible) |
| Linux | ARM64 | KVM enabled (`/dev/kvm` accessible) |
| Windows (WSL2) | x86_64 | WSL2 with KVM support |

<Warning>
  macOS Intel (`x86_64`) is not supported.
</Warning>

## Verify virtualization support

<Tabs>
  <Tab title="macOS">
    ```bash
    sw_vers
    uname -m
    ```
  </Tab>
  <Tab title="Linux">
    ```bash
    grep -E 'vmx|svm' /proc/cpuinfo
    ls -l /dev/kvm
    ```
  </Tab>
  <Tab title="Windows (WSL2)">
    ```bash
    wsl.exe -l -v
    ls -l /dev/kvm
    id -nG | tr ' ' '\n' | grep -x kvm
    ```
  </Tab>
</Tabs>

## BoxLite and BoxRun are different setup flows

- BoxLite setup belongs in the language quickstarts and SDK reference.
- BoxRun setup belongs in the BoxRun tab because it is a separate management layer with its own lifecycle and operating model.
