BoxLite is an embeddable sandbox runtime for creating isolated Linux boxes from your own application code. This documentation is organized around one onboarding path:

1. Understand what BoxLite is.
2. Decide whether you need BoxLite or BoxRun.
3. Pick a language quickstart.
4. Move into tutorials, production guides, and SDK reference.

Use this page as the routing point, not as the full product explanation.
