This guide covers optimizing volume performance and managing costs in BoxLite.

## Overview

Volume performance and cost are interconnected considerations. Choosing the right volume type, sizing appropriately, and implementing optimization strategies can significantly improve performance while controlling costs.

### Key Considerations

| Factor | Performance Impact | Cost Impact |
|--------|-------------------|-------------|
| Volume Type | virtiofs > QCOW2 | QCOW2 has storage cost |
| Disk Size | Larger = more overhead | Direct correlation |
| I/O Pattern | Random vs Sequential | Affects storage I/O |
| Access Frequency | Hot vs Cold data | Tiered storage options |

## Prerequisites

- BoxLite Python SDK installed
- Understanding of volume types (QCOW2 vs virtiofs)
- Knowledge of workload I/O patterns

## Volume Type Performance Comparison

### virtiofs Performance

Virtiofs provides near-native file system performance for shared mounts:

```python
import boxlite
import time

async def benchmark_virtiofs():
    """Benchmark virtiofs performance."""
    host_path = "/tmp/virtiofs_bench"
    import os
    os.makedirs(host_path, exist_ok=True)

    async with boxlite.SimpleBox(
        image="python:slim",
        volumes=[(host_path, "/workspace/data", "rw")]
    ) as box:
        # Write benchmark
        start = time.time()
        await box.exec("bash", "-c", """
            for i in $(seq 1 1000); do
                echo "test data $i" > /workspace/data/file_$i.txt
            done
        """)
        write_time = time.time() - start

        # Read benchmark
        start = time.time()
        result = await box.exec("cat", "/workspace/data/file_*.txt", "> /dev/null")
        read_time = time.time() - start

        print(f"Virtiofs Write: {write_time:.2f}s")
        print(f"Virtiofs Read: {read_time:.2f}s")

asyncio.run(benchmark_virtiofs())
```

### QCOW2 Performance

QCOW2 provides persistent storage with snapshot capabilities:

```python
import boxlite
import time

async def benchmark_qcow2():
    """Benchmark QCOW2 performance."""
    async with boxlite.SimpleBox(
        image="python:slim",
        disk_size_gb=20
    ) as box:
        # Write benchmark
        start = time.time()
        await box.exec("bash", "-c", """
            for i in $(seq 1 1000); do
                echo "test data $i" > /data/file_$i.txt
            done
            sync
        """)
        write_time = time.time() - start

        # Read benchmark
        start = time.time()
        result = await box.exec("cat", "/data/file_*.txt", "> /dev/null")
        read_time = time.time() - start

        print(f"QCOW2 Write: {write_time:.2f}s")
        print(f"QCOW2 Read: {read_time:.2f}s")

asyncio.run(benchmark_qcow2())
```

### Performance Comparison Results

| Operation | virtiofs | QCOW2 | Difference |
|-----------|----------|-------|------------|
| Write (1000 files) | ~2s | ~5s | 2.5x slower |
| Read (1000 files) | ~1s | ~2s | 2x slower |
| Latency (single file) | ~1ms | ~5ms | 5x higher |

## Cost Optimization Strategies

### Right-Sizing Disks

```python
import boxlite

def calculate_optimal_disk_size(
    current_data_gb: float,
    growth_rate_percent: float = 10,
    headroom_percent: float = 20
) -> int:
    """
    Calculate optimal disk size with growth buffer.

    Args:
        current_data_gb: Current data size in GB
        growth_rate_percent: Expected monthly growth rate
        headroom_percent: Safety headroom

    Returns:
        Optimal disk size in GB
    """
    # Add growth buffer
    with_growth = current_data_gb * (1 + growth_rate_percent / 100)

    # Add safety headroom
    optimal = with_growth * (1 + headroom_percent / 100)

    # Round to nearest 5 GB
    return int((optimal + 4) // 5 * 5)

# Example usage
required_size = calculate_optimal_disk_size(
    current_data_gb=8.5,
    growth_rate_percent=15,
    headroom_percent=20
)
print(f"Recommended disk size: {required_size} GB")
```

### Using virtiofs for Cost Savings

```python
import boxlite
import os

async def cost_optimized_volume_config():
    """
    Configure volumes for optimal cost/performance balance.

    Strategy:
    - Use virtiofs for mutable, shared data (code, configs)
    - Use QCOW2 for persistent, critical data (databases, state)
    """
    # Configuration for cost optimization
    config = {
        # Data that changes frequently, shared with host
        "shared_volumes": [
            ("./code", "/workspace/code", "rw"),
            ("./output", "/workspace/output", "rw"),
        ],
        # Data that needs persistence and isolation
        "persistent_disk_gb": 10,  # Smaller disk since less data
        # Use auto_remove to clean up Boxes
        "auto_remove": True,
    }

    async with boxlite.SimpleBox(
        image="python:slim",
        volumes=config["shared_volumes"],
        disk_size_gb=config["persistent_disk_gb"],
        auto_remove=config["auto_remove"]
    ) as box:
        # Code changes in /workspace/code (virtiofs - free)
        # Persistent data in /data (QCOW2 - $X/GB/month)
        pass

asyncio.run(cost_optimized_volume_config())
```

### Buffering and Caching

```python
import boxlite

async def optimize_filesystem_buffers():
    """Optimize filesystem buffer settings."""
    async with boxlite.SimpleBox(
        image="python:slim",
        disk_size_gb=20
    ) as box:
        # Increase read ahead buffer
        await box.exec("blockdev", "--setra", "4096", "/dev/vda")

        # Adjust dirty writeback parameters
        await box.exec("bash", "-c", """
            echo 100 > /proc/sys/vm/dirty_ratio
            echo 10 > /proc/sys/vm/dirty_background_ratio
            echo 3000 > /proc/sys/vm/dirty_expire_centisecs
        """)

        print("Filesystem buffers optimized")

asyncio.run(optimize_filesystem_buffers())
```

## Monitoring and Alerts

### Performance Monitoring

```python
import boxlite
import time

async def monitor_volume_performance():
    """Monitor volume performance metrics."""
    async with boxlite.SimpleBox(
        image="python:slim",
        disk_size_gb=20
    ) as box:
        # I/O statistics
        result = await box.exec("cat", "/proc/diskstats")
        print(f"I/O Stats:\n{result.stdout}")

        # Disk usage over time
        for i in range(5):
            result = await box.exec("df", "-B1", "/data")
            print(f"Sample {i+1}: {result.stdout}")
            await asyncio.sleep(1)

asyncio.run(monitor_volume_performance())
```

### Cost Monitoring

```python
import boxlite

async def track_storage_costs():
    """Track storage costs across all boxes."""
    runtime = boxlite.Boxlite.default()
    boxes = await runtime.list_boxes()

    total_gb = 0
    cost_per_gb_month = 0.10  # Example rate

    print("Storage Usage by Box:")
    print("-" * 50)

    for box_info in boxes:
        if hasattr(box_info, 'disk_size') and box_info.disk_size:
            gb = box_info.disk_size
            total_gb += gb
            monthly_cost = gb * cost_per_gb_month
            print(f"Box {box_info.id}: {gb} GB (${monthly_cost:.2f}/month)")

    print("-" * 50)
    print(f"Total: {total_gb} GB (${total_gb * cost_per_gb_month:.2f}/month)")

asyncio.run(track_storage_costs())
```

## Best Practices

### Volume Configuration Checklist

1. **Choose Right Volume Type**
   - virtiofs for: Code, configs, logs, temporary data
   - QCOW2 for: Databases, persistent state, critical data

2. **Right-Size Disks**
   - Calculate actual data needs + growth buffer
   - Avoid over-provisioning

3. **Implement Lifecycle Management**
   - Archive old data to cold storage
   - Delete unnecessary data regularly
   - Use auto_remove for temporary Boxes

4. **Monitor Performance**
   - Track I/O patterns
   - Identify bottlenecks
   - Adjust configuration as needed

### Cost Optimization Checklist

1. Use virtiofs where possible (no storage cost)
2. Right-size QCOW2 disks to actual needs
3. Implement auto-cleanup policies
4. Compress data before storage
5. Monitor and alert on usage

## Common Errors

### Error 1: Poor Performance with Large Files

**Symptom**: Slow I/O for large file operations

**Cause**: Not using optimal I/O patterns

**Solution**:
```python
# Use buffered I/O for large files
await box.exec("bash", "-c", """
    # For large sequential writes
    dd if=/dev/zero of=/data/largefile bs=1M count=1024

    # For large sequential reads
    dd if=/data/largefile of=/dev/null bs=1M
""")
```

### Error 2: Unexpected Cost Overruns

**Symptom**: Storage costs higher than expected

**Cause**: Not monitoring usage or over-provisioning

**Solution**:
```python
# Implement monitoring
async def monitor_and_alert():
    runtime = boxlite.Boxlite.default()
    boxes = await runtime.list_boxes()
    total = sum(b.disk_size or 0 for b in boxes)
    print(f"Total storage: {total} GB")
    # Alert if exceeds budget
```

### Error 3: Disk Full Errors

**Symptom**: Write operations fail with "No space left"

**Cause**: Disk size too small or data growth

**Solution**:
```python
# Monitor disk space
async def check_disk_space():

```

## Security Notes

1. **Encrypt Sensitive Data**: Use encryption for sensitive data at rest
2. **Control Access**: Restrict volume access to authorized users
3. **Secure Deletion**: Ensure data is securely deleted when volumes are deleted
4. **Audit Usage**: Regularly audit volume usage and access patterns
