This page is kept only as a compatibility target for older links.

BoxRun CLI documentation now has a single authority page at [BoxRun CLI Reference](/boxrun/cli). Use that page for supported commands, flags, examples, and upgrade guidance.

## Why this page exists

- Older BoxLite navigation and in-product links pointed to `/reference/cli`.
- The CLI belongs to BoxRun, not the BoxLite SDK reference.
- Keeping this page avoids broken inbound links while removing the duplicate source of truth.
